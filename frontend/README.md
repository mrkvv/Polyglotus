# Polyglotus — Frontend

React-приложение на Vite + TypeScript, построенное по методологии **Feature-Sliced Design (FSD)**.

---

## Установка Node.js и npm

Рекомендуемый способ — использовать **nvm (Node Version Manager)**. Он позволяет устанавливать несколько версий Node.js и легко переключаться между ними.

### macOS / Linux

1. Установить nvm:
   ```bash
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
   ```
2. Перезапустить терминал или выполнить:
   ```bash
   source ~/.bashrc   # или ~/.zshrc, если используете Zsh
   ```
3. Установить нужную версию Node.js:
   ```bash
   nvm install 20
   nvm use 20
   ```

> Официальная документация: https://github.com/nvm-sh/nvm

---

### Windows

На Windows используется отдельный порт — **nvm-windows**:

1. Скачать установщик `nvm-setup.exe` со страницы релизов:
   https://github.com/coreybutler/nvm-windows/releases/latest
2. Запустить установщик и следовать инструкциям.
3. Открыть новый терминал (PowerShell или cmd) и выполнить:
   ```powershell
   nvm install 20
   nvm use 20
   ```

> Официальная документация: https://github.com/coreybutler/nvm-windows

---

### Альтернатива — прямая установка

Если nvm не нужен, Node.js (вместе с npm) можно установить напрямую с официального сайта:
**https://nodejs.org** — выбрать LTS-версию.

---

### Проверка установки

```bash
node -v   # должно вывести v20.x.x или выше
npm -v    # должно вывести 9.x.x или выше
```

## Команды

### Запуск в режиме разработки

```bash
npm run dev
```

Запускает dev-сервер Vite. По умолчанию приложение доступно по адресу:
**http://localhost:5173**

Сервер поддерживает HMR (Hot Module Replacement) — изменения в файлах применяются мгновенно без перезагрузки страницы.

---

### Сборка для продакшена

```bash
npm run build
```

Команда выполняет два шага последовательно:
1. `tsc -b` — проверка типов TypeScript и генерация деклараций.
2. `vite build` — бандлинг и минификация. Готовые файлы помещаются в папку `dist/`.

---

### Предпросмотр продакшен-сборки

```bash
npm run preview
```

Запускает локальный статический сервер, который раздаёт содержимое папки `dist/`. Используется для проверки финальной сборки перед деплоем. По умолчанию доступен по адресу:
**http://localhost:4173**

> Команду нужно запускать **после** `npm run build`.

---

### Линтинг

```bash
npm run lint
```

Запускает ESLint по всем файлам проекта. Помогает найти синтаксические ошибки и нарушения кодстайла до запуска сборки.

## Псевдонимы путей (Path Aliases)

В проекте настроены короткие импорты для каждого слоя FSD:

| Псевдоним    | Путь              |
|--------------|-------------------|
| `@app`       | `src/app`         |
| `@pages`     | `src/pages`       |
| `@widgets`   | `src/widgets`     |
| `@features`  | `src/features`    |
| `@entities`  | `src/entities`    |
| `@shared`    | `src/shared`      |

Пример использования:

```ts
import { HomePage } from '@pages/home-page';
import { userStore } from '@entities/user';
import { AuthContext } from '@features/auth';
```

## Структура проекта

```
src/
├── app/          # Инициализация приложения, провайдеры, роутинг
├── pages/        # Страницы (композиция виджетов и фич)
├── widgets/      # Самостоятельные блоки UI (Sidebar и др.)
├── features/     # Пользовательские сценарии (auth и др.)
├── entities/     # Бизнес-сущности (user и др.)
└── shared/       # Переиспользуемые утилиты, типы, стили, конфиги
```

## Стек технологий

- **React 18** — UI-библиотека
- **TypeScript 5** — статическая типизация
- **Vite 5** — сборщик и dev-сервер
- **React Router DOM 6** — клиентский роутинг
- **SCSS / CSS Modules** — стилизация компонентов
- **Feature-Sliced Design** — архитектурная методология
