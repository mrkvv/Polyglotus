## UserService

Обязанности:
- Вход в аккаунт - через яндекс, пользователь входит и мы получаем его id в яндексе, имя и фамилию. Запись о пользователе добавляется (или обновляется, если повторный вход) в нашу БД, генерируется токен сессии в Redis.
- Дает информацию по пользователю (id, имя, фамилия, стрик, уровень знаний, аватар, интересующие темы)
- Выход из аккаунта (удаление токена)
- Манипуляции с настройками пользователя (уровень знаний, темы, №аватара)

## TrainingService

Обязанности:
- В тренировках без ИИ создает выборки с правильными ответами (в дистракторы попадают слова из словаря этого же пользователя с теми же частями речи)
- В тренировке "Дополни предложение" обращается к AIService для генерации предложения с нужным словом (в запросе его и отправляет)
- Отправляет клиенту задания пачкой, с уже прописанными правильными ответами (в ответ ждет только лишь слова, которым нужно увеличить прогресс пользователя)


---
## AIService
Задача: вся работа с LLM

Обязанности:
- Общаться с пользователем через LLM
- Вести счетчик запросов, которые уже обрабатывает LLM и в случае, когда запросов слишком много, возвращать пользователю ошибку с текстом "ИИ сейчас занят, попробуйте позже"
- Смотреть, не превышен ли объем контекста при запросе в LLM. Если да - закончить диалог.
- Обращается в EmbedderService за TopK словами по теме (каждые N запросов?)
- Генерирует предложение для TrainingService

## DictionaryService

Обязанности:
- Обращение к внешней API для получения переводов слов
- Добавление слов в каталог
- Добавление (удаление) слов в словари пользователей
- Получение словаря пользователя
- Мотивационные фразы, слова дня


---
## EmbedderService
Задача: считать вектор принадлежности слов и диалогов к темам

Обязанности:
- В фоне обращается к хранилищу со всеми словами и считает им вектора (список слов - общий, поэтому подсчет для 1 слова будет 1 раз).
- По запросу считает вектор диалога с LLM (диалог прикрепляется в запросе) и возвращает TopK слов пользователя, подходящих под тему
